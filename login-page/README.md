# Login Page (Vite + React)

## Quick Start

### Install
```powershell
Push-Location "C:\Users\Birendra_Mukhiya\Desktop\Login Page"
npm install
```

### Develop
```powershell
npm run dev
```
Open http://localhost:5173 in your browser.

### Build
```powershell
npm run build
npm run preview
```

Your original component remains at `login.jsx`; the app uses `src/components/Login.jsx`.
